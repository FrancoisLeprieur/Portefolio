🌐 Projet S1 · RT3

Site web dédié à une passion

HTML / CSS Git / GitHub Design responsive Solo

Présentation du projet

Catégorie
RT3 — Développement
Période
Semestre 1
Format
Solo
Rôle
Développeur web

Conception et développement de A à Z d'un site internet multipage sur le tennis : architecture des pages, intégration HTML/CSS responsive, gestion du versionnement avec Git et déploiement sur GitHub Pages. Projet mené seul avec une planification sur Trello.


🌐 Voir le site en ligne ↗

Contexte & Démarche

📋 Contexte

Projet individuel RT3 pour mettre en pratique les compétences web acquises en cours. Sujet libre — j'ai choisi de créer un site sur le tennis, ma passion sportive principale.

🔧 Démarche

Maquettage sur papier → carte mentale pour structurer les pages → intégration HTML/CSS responsive → commits réguliers sur Git → déploiement sur GitHub Pages. Suivi des tâches sur Trello.

Documents produits & ce qu'ils prouvent

Document 1 / 2
Tableau Trello de gestion du projet

J'ai utilisé Trello pour organiser et planifier le développement du site : les tâches sont réparties en colonnes (À faire / En cours / Terminé) avec des délais associés à chaque carte. Chaque fonctionnalité du site correspond à une tâche.

Ce tableau prouve que je sais gérer un projet en autonomie : décomposer un objectif complexe en tâches concrètes, prioriser et respecter les délais — compétence essentielle en environnement professionnel.

Document 2 / 2
Carte mentale de l'architecture du site

Avant de coder, j'ai réalisé cette carte mentale pour structurer l'architecture du site : pages prévues, contenu de chaque section, liens de navigation entre les pages et ressources nécessaires (images, textes…).

Cette démarche de conception en amont démontre ma capacité à planifier avant d'exécuter, ce qui m'a permis d'éviter les allers-retours inutiles dans le code et de livrer un site cohérent dans les délais.

Bilan

✅ Points forts

Site complet et visuellement soigné. Bonne pratique du versionnement Git. Code propre et commenté. Bonne gestion du projet en autonomie — délais respectés grâce à Trello.

⚠️ À améliorer

Le site gagnerait à intégrer du JavaScript pour le rendre plus interactif (animations, formulaires…). Cette compétence n'était abordée qu'au deuxième semestre — elle constitue une évolution naturelle du projet.
